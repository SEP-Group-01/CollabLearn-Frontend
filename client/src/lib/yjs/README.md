# Yjs Collaboration Dependencies

Add these dependencies to your package.json:

```json
{
  "dependencies": {
    "yjs": "^13.6.7",
    "y-websocket": "^2.0.4",
    "y-protocols": "^1.0.6"
  },
  "devDependencies": {
    "@types/yjs": "^13.0.0"
  }
}
```

Install with:

```bash
npm install yjs y-websocket y-protocols
npm install --save-dev @types/yjs
```

Or with yarn:

```bash
yarn add yjs y-websocket y-protocols
yarn add --dev @types/yjs
```
